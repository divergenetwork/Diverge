Add an account

An account is a GitHub or Google sign-in. At identity.diverge.network it has one username, which it sets once and can never change, and it owns every subject that begins with it, written username.name. An account with no username can sign nothing in until one is set here. Anyone who can open this page can add or remove accounts and set a username, and any agent attached to this tool can sign in as any of them. Removing an account here does not sign out what it already signed in, and does not give up its username.
