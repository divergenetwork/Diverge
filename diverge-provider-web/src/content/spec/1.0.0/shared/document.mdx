Every image ships at most one document, the file `DIVERGE.md` in the
directory `.diverge` at the root of the image's filesystem: the path
`/.diverge/DIVERGE.md`. The document states whether the image's
program is an agent, a standalone tool or a dependency tool, what the
`arguments` of a container of the image may be, what a container of
the image needs, and, of a tool, how it is kept running. This section
defines the file, its size, and the JSON object a server sends for
it. The image's icons are three further files of that directory,
which the document does not name: [Icon](/shared/icon/) defines them.
A server reads no file of that directory but the document and the
three icons.

## The file

- **The frontmatter.** The file begins with a line that is exactly
  `---`. The lines after it, up to the next line that is exactly
  `---`, are the frontmatter.
- **One JSON object.** The frontmatter is exactly one JSON object.
- **`type`.** The object has the member `type`. Its value is exactly
  the string `agent`, exactly the string `standalone_tool` or exactly
  the string `dependency_tool`. A document whose `type` is `agent` is
  an agent's document. A document whose `type` is `standalone_tool` is
  a standalone tool's document. A document whose `type` is
  `dependency_tool` is a dependency tool's document. The three are
  different documents: the members a frontmatter has, besides `type`,
  are the members of its type, stated below. The string `tool` is not
  a `type`.
- **One type.** An image has exactly one document, and a document has
  exactly one `type`. No image is of two types.
- **The members of every type.** A frontmatter of any type has the
  member `name`, a string, the member `description`, a string, the
  member `schema`, a JSON object, the member `memory` and the member
  `disk`. It has at most two further members that every type has:
  `secrets`, an array, and `frontend`, a boolean.
- **`name`.** The value of `name` is at least 1 byte and at most 128
  bytes long. It is one or more runs, joined by separators. A run is
  one or more bytes, each a byte of `a` to `z`, a byte of `A` to `Z`
  or a byte of `0` to `9`. A separator is exactly `.`, exactly `_`, exactly `__`, or one
  or more `-`. Exactly one separator stands between two runs. The
  value begins with a run and ends with a run. The value has no other
  byte: it has no space and no byte that is not ASCII. Two values
  that differ only in the case of a letter are two names. This is the
  form of one path component of the name of an OCI repository, except
  that such a component has no byte of `A` to `Z`. The value states
  what the image calls itself. No rule makes it unique: two images
  may have the same `name`.
- **`description`.** The value of `description` is a description as
  [The description](/endpoints/daemons-announce/request/#the-description)
  defines it: one line of plain text, of at least one and at most 132
  characters. It states what the image is. It is the only description
  an image has: no request of the Protocol carries a description of
  an image, and a server keeps none beside the image.
- **`memory`.** The value of `memory` is a whole number of bytes, at
  least `0` and at most `18446744073709551615`, which is 2 to the
  power 64 less 1. It states the memory a container of the image
  needs.
- **`disk`.** The value of `disk` is a whole number of bytes, at least
  `0` and at most `18446744073709551615`. It states the bytes a
  container of the image needs to write to its own filesystem.
- **`secrets`.** The value of `secrets` is an array of zero or more
  objects. Each object has exactly two members: `name`, a string, and
  `description`, a string. The array states every secret the image's
  program takes under any `arguments`. A frontmatter without the
  member states that the program takes none.
- **A secret's `name`.** The value of `name` is one line of plain
  text: it has no control character, it has at least one and at most
  75 characters, counted as Unicode scalar values, and it has no
  whitespace at its start or at its end. No two objects of one
  `secrets` array have the same `name`.
- **A secret's `description`.** The value of `description` is a
  description as
  [The description](/endpoints/daemons-announce/request/#the-description)
  defines it. It states what the secret is.
- **The members of an agent's.** An agent's frontmatter has at most
  two members further: `chat` and `structured_decisions`.
- **`chat`.** The value of `chat` is the boolean `false` or an object
  of exactly one member, `prompt_modalities`.
- **`structured_decisions`.** The value of `structured_decisions` is
  the boolean `false` or an object of exactly three members,
  `prompt_modalities`, `instruction_modalities` and
  `choice_modalities`.
- **The modalities.** Each of those four members is an object of
  exactly three members, `image`, `audio` and `file`, each a boolean.
- **Never `true`.** A frontmatter in which `chat` or
  `structured_decisions` is `true` is not a document.
- **At least one.** In an agent's frontmatter, at least one of `chat`
  and `structured_decisions` is an object. An agent's frontmatter in
  which both are `false`, in which both are absent, or in which one is
  `false` and the other is absent, is not a document.
- **The members of a standalone tool's.** A standalone tool's
  frontmatter has exactly one member further: `mode`.
- **The members of a dependency tool's.** A dependency tool's
  frontmatter has exactly two members further: `mode` and `scope`.
- **`mode`.** The value of `mode` is exactly the string `lazy` or
  exactly the string `eager`. It states how a caller keeps a tool
  container of the image running.
- **`scope`.** The value of `scope` is exactly the string `instance`
  or exactly the string `global`. It states how far a caller shares
  one tool container of the image among the agent containers that
  declare it.
- **A member of another type.** A member of one type is not a member
  of another. `chat` and `structured_decisions` are members of an
  agent's frontmatter only. `mode` is a member of a standalone tool's
  and of a dependency tool's only. `scope` is a member of a
  dependency tool's only. A frontmatter that has a member of a type
  that is not its own, whatever the member's value, `false` included,
  is not a document.
- **No other member.** A frontmatter has no member that is not a
  member of its type. A frontmatter that has any other member,
  whatever its name and whatever its value, is not a document.
- **The body.** Every byte after the closing line is the body.
- **UTF-8.** The file is read as UTF-8.

## The size

- **The limit.** The file is at most `1048576` bytes long. `1048576`
  is 2 to the power 20.
- **What is measured.** The length is the number of bytes of the file
  as the image's filesystem holds it. Nothing is parsed, decoded or
  decompressed before the length is taken.
- **Exactly the limit.** A file of exactly `1048576` bytes is within
  the limit. A file of `1048577` bytes or more is over it.
- **Over the limit.** A server reads no byte of a file that is over
  the limit, parses none of it, and sends no part of it. The server
  answers that the file is too large, as the page of the channel that
  asked states.
- **Not the frame.** The limit bounds the file. It does not bound the
  JSON object a server sends for the file, and the tag byte of a
  frame is not counted.

## The document

A server that reads the file sends exactly one JSON object. The object
is an agent's document, a standalone tool's document or a dependency
tool's document, as the file is.

- **`type`.** A string: exactly `agent`, exactly `standalone_tool` or
  exactly `dependency_tool`, the frontmatter's `type`. A reader
  decides by this member which of the three documents the object is.
- **`name`.** A string: the frontmatter's `name`, the image's own
  name, as the image states it.
- **`description`.** A string: the frontmatter's `description`, what
  the image is, in one line, as the image states it.
- **`schema`.** A JSON object: the frontmatter's `schema`, the JSON
  Schema of the `arguments` a container of the image accepts.
- **`memory`.** A number: the frontmatter's `memory`.
- **`disk`.** A number: the frontmatter's `disk`.
- **`secrets`.** Present only when the frontmatter's `secrets` has at
  least one object, with exactly the frontmatter's objects, in the
  frontmatter's order. Its absence states that the program takes no
  secret.
- **`body`.** A string: the body, verbatim.
- **`frontend`.** Present only with the value `true`, when the
  frontmatter's `frontend` is `true`. It states that the image's
  program serves a frontend, as the
  [frontend](/container-proxy-endpoints/frontend/) endpoint provides.
  Its absence states that the program serves none.
- **`chat`.** In an agent's document only. Present only with the
  frontmatter's object, when the frontmatter's `chat` is an object. It
  states how the agent's program chats. Its absence states that the
  program does not chat.
- **`structured_decisions`.** In an agent's document only. Present
  only with the frontmatter's object, when the frontmatter's
  `structured_decisions` is an object. It states how the agent's
  program makes structured decisions. Its absence states that the
  program makes no structured decision.
- **An agent's document has at least one of the two.** At least one of
  `chat` and `structured_decisions` is present.
- **`mode`.** In a standalone tool's document and in a dependency
  tool's document only. A string: the frontmatter's `mode`.
- **`scope`.** In a dependency tool's document only. A string: the
  frontmatter's `scope`.
- **A tool's document has neither `chat` nor `structured_decisions`.**
  A standalone tool's document has neither, and a dependency tool's
  document has neither.
- **The count.** An agent's document has at least eight and at most
  eleven members. A standalone tool's document has at least eight and
  at most ten. A dependency tool's document has at least nine and at
  most eleven.
- **No other member.** The server sends no member further.

## Not a document

A file is not a document when any of the following holds. A server
that reads a file that is not a document answers an error, as the page
of the channel that asked states, and sends no part of the file.

1. The file does not begin with a line that is exactly `---`.
2. No later line is exactly `---`.
3. The frontmatter is not exactly one JSON object.
4. The object has no member `type`, or the value of `type` is not
   exactly the string `agent`, exactly the string `standalone_tool`
   or exactly the string `dependency_tool`.
5. The object lacks `name`, `description`, `schema`, `memory` or
   `disk`; the object is a standalone tool's or a dependency tool's
   and lacks `mode`; the object is a dependency tool's and lacks
   `scope`; or a member the object has is not of the form
   [The file](#the-file) states for it. A `description` that is not a
   description as
   [The description](/endpoints/daemons-announce/request/#the-description)
   defines it is such a member, in the object and in an object of
   `secrets`.
6. The object has a member that is not a member of its type. In a
   tool's frontmatter of either type, `chat` and
   `structured_decisions` are such members. In an agent's, `mode` and
   `scope` are. In a standalone tool's, `scope` is.
7. The value of `name` is not as [The file](#the-file) states the
   `name` of a frontmatter.
8. `schema` is not an object.
9. A `name` of `secrets` is not as [The file](#the-file) states a
   secret's `name`, or two objects of `secrets` have the same `name`.
10. The `type` is `agent`, and neither `chat` nor
    `structured_decisions` is an object.
11. The bytes of the file are not UTF-8.

A file that is over the limit of [The size](#the-size) is not read,
and is neither a document nor not a document: it is too large.
