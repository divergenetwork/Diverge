Every image ships at most one document, the file `DIVERGE.md` in the
directory `.diverge` at the root of the image's filesystem: the path
`/.diverge/DIVERGE.md`. The document states whether the image's
program is an agent or a tool, what the `arguments` of a container of
the image may be. This section defines the file, its size, and the
JSON object a server sends for it. The image's icons are three
further files of that directory, which the document does not name:
[Icon](/shared/icon/) defines them. A server reads no file of that
directory but the document and the three icons.

## The file

- **The frontmatter.** The file begins with a line that is exactly
  `---`. The lines after it, up to the next line that is exactly
  `---`, are the frontmatter.
- **One JSON object.** The frontmatter is exactly one JSON object.
- **`type`.** The object has the member `type`. Its value is exactly
  the string `agent` or exactly the string `tool`. A document whose
  `type` is `agent` is an agent's document. A document whose `type` is
  `tool` is a tool's document. The two are different documents: the
  members a frontmatter has, besides `type`, are the members of its
  type, stated below.
- **The members of both types.** A frontmatter of either type has the
  member `name`, a string, the member `description`, a string, and
  the member `schema`, a JSON object. It has at most one further
  member that both types have: `frontend`, a boolean.
- **`description`.** The value of `description` is a description as
  [The description](/endpoints/daemons-announce/request/#the-description)
  defines it: one line of plain text, of at least one and at most 132
  characters. It states what the image is. It is the only description
  an image has: no request of the Protocol carries a description of
  an image, and a server keeps none beside the image.
- **The members of an agent's.** An agent's frontmatter has at most
  two members further: `chat` and `structured_decisions`.
- **`chat`.** The value of `chat` is the boolean `false` or an object
  of exactly one member, `prompt_modalities`.
- **`structured_decisions`.** The value of `structured_decisions` is
  the boolean `false` or an object of exactly three members,
  `prompt_modalities`, `instruction_modalities` and
  `choice_modalities`.
- **The modalities.** Each of those four members is an object of
  exactly three members, `image`, `audio` and `file`, each a boolean.
- **Never `true`.** A frontmatter in which `chat` or
  `structured_decisions` is `true` is not a document.
- **At least one.** In an agent's frontmatter, at least one of `chat`
  and `structured_decisions` is an object. An agent's frontmatter in
  which both are `false`, in which both are absent, or in which one is
  `false` and the other is absent, is not a document.
- **The members of a tool's.** A tool's frontmatter has no member
  further. A tool's frontmatter that has the member `chat` or the
  member `structured_decisions`, whatever the member's value, `false`
  included, is not a document.
- **No other member.** A frontmatter has no member that is not a
  member of its type. A frontmatter that has any other member,
  whatever its name and whatever its value, is not a document.
- **The body.** Every byte after the closing line is the body.
- **UTF-8.** The file is read as UTF-8.

## The size

- **The limit.** The file is at most `1048576` bytes long. `1048576`
  is 2 to the power 20.
- **What is measured.** The length is the number of bytes of the file
  as the image's filesystem holds it. Nothing is parsed, decoded or
  decompressed before the length is taken.
- **Exactly the limit.** A file of exactly `1048576` bytes is within
  the limit. A file of `1048577` bytes or more is over it.
- **Over the limit.** A server reads no byte of a file that is over
  the limit, parses none of it, and sends no part of it. The server
  answers that the file is too large, as the page of the channel that
  asked states.
- **Not the frame.** The limit bounds the file. It does not bound the
  JSON object a server sends for the file, and the tag byte of a
  frame is not counted.

## The document

A server that reads the file sends exactly one JSON object. The object
is an agent's document or a tool's document, as the file is.

- **`type`.** A string: exactly `agent` or exactly `tool`, the
  frontmatter's `type`. A reader decides by this member which of the
  two documents the object is.
- **`name`.** A string: the frontmatter's `name`, the image's own
  name, as the image states it.
- **`description`.** A string: the frontmatter's `description`, what
  the image is, in one line, as the image states it.
- **`schema`.** A JSON object: the frontmatter's `schema`, the JSON
  Schema of the `arguments` a container of the image accepts.
- **`body`.** A string: the body, verbatim.
- **`frontend`.** Present only with the value `true`, when the
  frontmatter's `frontend` is `true`. It states that the image's
  program serves a frontend, as the
  [frontend](/container-proxy-endpoints/frontend/) endpoint provides.
  Its absence states that the program serves none.
- **`chat`.** In an agent's document only. Present only with the
  frontmatter's object, when the frontmatter's `chat` is an object. It
  states how the agent's program chats. Its absence states that the
  program does not chat.
- **`structured_decisions`.** In an agent's document only. Present
  only with the frontmatter's object, when the frontmatter's
  `structured_decisions` is an object. It states how the agent's
  program makes structured decisions. Its absence states that the
  program makes no structured decision.
- **An agent's document has at least one of the two.** At least one of
  `chat` and `structured_decisions` is present.
- **A tool's document has neither.** A tool's document has neither
  `chat` nor `structured_decisions`.
- **The count.** An agent's document has at least six and at most
  eight members. A tool's document has at least five and at most
  six.
- **No other member.** The server sends no member further.

## Not a document

A file is not a document when any of the following holds. A server
that reads a file that is not a document answers an error, as the page
of the channel that asked states, and sends no part of the file.

1. The file does not begin with a line that is exactly `---`.
2. No later line is exactly `---`.
3. The frontmatter is not exactly one JSON object.
4. The object has no member `type`, or the value of `type` is not
   exactly the string `agent` or exactly the string `tool`.
5. The object lacks `name`, `description` or `schema`, or a member it
   has is not of the form [The file](#the-file) states for it. A
   `description` that is not a description as
   [The description](/endpoints/daemons-announce/request/#the-description)
   defines it is such a member.
6. The object has a member that is not a member of its type. In a
   tool's frontmatter, `chat` and `structured_decisions` are such
   members.
7. `schema` is not an object.
8. The `type` is `agent`, and neither `chat` nor
   `structured_decisions` is an object.
9. The bytes of the file are not UTF-8.

A file that is over the limit of [The size](#the-size) is not read,
and is neither a document nor not a document: it is too large.
