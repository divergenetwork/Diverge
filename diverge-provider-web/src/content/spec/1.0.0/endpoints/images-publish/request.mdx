The payload of the request is the tag byte followed by the request in
the postcard wire format, as the postcard reading of
[Notation](/endpoints/#notation) provides:

```text
[19][digest_len: varint][digest: utf8 …][registry_len: varint][registry: utf8 …][name_len: varint][name: utf8 …][tags: varint][tag_len: varint][tag: utf8 …]…[0]
[19][digest_len: varint][digest: utf8 …][registry_len: varint][registry: utf8 …][name_len: varint][name: utf8 …][tags: varint][tag_len: varint][tag: utf8 …]…[1][username_len: varint][username: utf8 …][password_len: varint][password: utf8 …]
```

- **`digest`.** The manifest digest of the image, UTF-8, of the form
  `<algorithm>:<hex>`, preceded by its byte length as a varint. It is
  the `digest` of an image in the client's
  [images::list](/endpoints/images-list/) listing.
- **`reference`.** Two strings, each UTF-8 preceded by its byte
  length as a varint: `registry`, the host of the registry, and
  `name`, the repository path there, as
  [images::read](/endpoints/images-read/request/) states them. The
  image is `<registry>/<name>@<digest>` at the registry once
  published.
- **`tags`.** A varint count, which may be `0`, followed by that many
  tags, each UTF-8 preceded by its byte length as a varint. A tag is
  one to `128` characters, each a letter, a digit, `_`, `.` or `-`,
  the first neither `.` nor `-`. With no tag, the image is published
  by its digest alone.
- **`credential`.** One byte: `0`, the server writes as nobody; or
  `1`, followed by `username` and `password`, each UTF-8 preceded by
  its byte length as a varint. The password is whatever the registry
  accepts beside the username.
- **A name or a tag that is not one.** A `name` that is not a
  repository path, and a tag that is not of the form above, decode,
  and are answered with the byte `5` alone, as
  [Response](/endpoints/images-publish/response/) states.
- **Bytes after the request.** A server ignores every byte that
  follows the `credential` field.
- **Malformed.** A payload with no byte, a payload whose first byte
  is not `19`, and a payload whose bytes after the tag do not decode
  as the request are malformed. [Endpoints](/endpoints/) states how a
  server answers a request it cannot read.
