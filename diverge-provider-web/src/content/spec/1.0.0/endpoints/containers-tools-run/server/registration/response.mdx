```text
[0]                  deployed: the client holds the container to its permissions
[1][error JSON …]    not deployed
```

- **The sequence.** Exactly one channel response, followed by the
  channel response finish. The byte `0`, with nothing after it, lets the run go on to its
  id. The byte `1`, followed by exactly one JSON value
  in the form defined on the [volumes::list response](/endpoints/volumes-list/response/)
  page, is the run's error, in the client's words: the server stops
  the container and sends the error as the scope's one response. A
  channel response finish that no channel response precedes is the
  run's error too.
- **Malformed.** A channel response with no byte, a channel response whose first byte is neither `0`
  nor `1`, and a channel response whose bytes after `1` are not one JSON value are
  the run's error. A channel response whose first byte is `0` is read by that byte alone; bytes after it are not read.

The channel response is defined by `diverge-sdk-rs/src/shared/containers/registration/response/frame.rs`:
