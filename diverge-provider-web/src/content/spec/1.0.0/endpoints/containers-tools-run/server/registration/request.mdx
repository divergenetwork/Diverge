```text
[15][request JSON …]
```

- **`id`.** A string: the id of the run the container is registered
  for, as the server minted it and as the response carries it after
  the channel has ended. The server has
  entered the container among those it runs when it sends this, so a
  [containers::fuse_serve](/endpoints/containers-fuse-serve/) naming the id is
  answered while the channel is open.
- **`dependencies`.** Absent. A tool container declares no
  dependencies, and the server carries none on a tools-run scope.
- **`permissions`.** An array of grants, in the order the program
  declared them; absent when empty. Each grant is an object of
  exactly one member named for a kind, whose value is a bare array of
  making actions, an object of `actions` and `within`, or an object
  of `actions`, `within` and `tags`. A `within` is exactly one of
  three forms. The first form is the string `any`, which reaches
  every record of the kind. The second form is an object of exactly
  one member, the kind's list, an array that names records one by
  one; it reaches exactly the records listed and no other, whatever
  their tags, and an empty list reaches nothing. The third form is an
  object of `all_tags` and `any_tags`, which reaches the records
  whose tags pass both. No `within` carries a list and tags together:
  an object that has a list's member and a tags member does not
  decode. The list's member is `identities` for accounts, for
  identities, for providers, for the daemons through providers and
  for images; `ids` for agent templates, for standalone tool
  templates and for remote daemons; `agents` for agents; `tools` for
  standalone tools, for connected standalone tools and for
  dependency tools; `names` for roles; `compartments` for the
  Postgres compartments; and `volumes` for volumes. An agent and a standalone tool are each
  listed as an object of exactly two members, `template`, a string,
  and `index`, an unsigned integer: the record of that index among
  the records made from that template. Over agents alone, a `within`
  may also be the string `attached`, which reaches the agents
  attached to the tool, or the string `never_active`, which reaches
  the agents that have never run. The server relays the array as the
  proxy sent it and reads none of it.
- **Malformed.** A channel request whose payload does not decode as
  stated is answered by a channel response finish that no channel
  response precedes, and the server does nothing else for it.
