```text
[0][the file's bytes …]   the 512 by 512 PNG icon
[1]                       the image ships no such icon
[2][error JSON …]         the file is not a valid icon, or could not be read
[3]                       the file is larger than 1048576 bytes
```

- **The sequence.** Exactly one channel response, followed by the
  channel response finish. A channel response finish that no channel
  response precedes states that the server did not serve the
  question.
- **The frame.** The payload is the frame that
  [Icon](/shared/icon/#the-frame) defines, for the file
  `/.diverge/icon-512.png`, decided in the order that
  [Icon](/shared/icon/#the-order) states.
- **The bytes.** After the byte `0`, every byte of the payload is a
  byte of the file, in order, exactly as the image holds it. No length
  precedes them and no byte follows them. They number at most
  `1048576`, and they are a valid PNG icon of side `512`, as [Icon](/shared/icon/#a-valid-png-icon) states.
- **One message.** The server sends the whole file in the one channel
  response. The file is not divided across channel responses.
- **Malformed.** A payload with no byte, a payload whose first byte
  is none of `0`, `1`, `2` and `3`, and a payload whose bytes after
  `2` do not parse as the error are malformed. A payload whose first
  byte is `1` or `3` is read by that byte alone; bytes after it are
  not read. No payload whose first byte is `0` is malformed.
