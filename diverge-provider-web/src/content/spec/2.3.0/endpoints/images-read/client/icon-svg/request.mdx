```text
[5]
```

- **The tag.** The byte `5` and nothing more. The request names
  no image and no file: the image is the image of the scope, and the
  file is the file that the member `svg` of its document's
  `icons` names.
- **Bytes after the tag.** The server ignores any bytes that follow
  the tag.
