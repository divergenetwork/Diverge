Every image ships at most one document, the file `DIVERGE.md` in the
directory `.diverge` at the root of the image's filesystem: the path
`/.diverge/DIVERGE.md`. The document states what the
`arguments` of a container of the image may be, and names the icons
the image ships. This section defines the file, its size, and the
JSON object a server sends for it. [Icon](/shared/icon/) defines the
icons. A server reads no file of that directory but the document and
the files the document's `icons` names.

## The file

- **The frontmatter.** The file begins with a line that is exactly
  `---`. The lines after it, up to the next line that is exactly
  `---`, are the frontmatter.
- **One JSON object.** The frontmatter is exactly one JSON object. It
  has the member `name`, a string, and the member `schema`, a JSON
  object, and at most four further members: `frontend`, a boolean;
  `icons`; `chat`; and `structured_decisions`. The frontmatter has no
  other member.
- **`icons`.** The value of `icons` is an object of at most three
  members, `svg`, `512` and `64`, each a string, and no other member.
  Each string is an icon name, as [Icon](/shared/icon/#the-name)
  defines one.
- **`chat`.** The value of `chat` is the boolean `false` or an object
  of exactly one member, `prompt_modalities`.
- **`structured_decisions`.** The value of `structured_decisions` is
  the boolean `false` or an object of exactly three members,
  `prompt_modalities`, `instruction_modalities` and
  `choice_modalities`.
- **The modalities.** Each of those four members is an object of
  exactly three members, `image`, `audio` and `file`, each a boolean.
- **Never `true`.** A frontmatter in which `chat` or
  `structured_decisions` is `true` is not a document.
- **The body.** Every byte after the closing line is the body.
- **UTF-8.** The file is read as UTF-8.

## The size

- **The limit.** The file is at most `1048576` bytes long. `1048576`
  is 2 to the power 20.
- **What is measured.** The length is the number of bytes of the file
  as the image's filesystem holds it. Nothing is parsed, decoded or
  decompressed before the length is taken.
- **Exactly the limit.** A file of exactly `1048576` bytes is within
  the limit. A file of `1048577` bytes or more is over it.
- **Over the limit.** A server reads no byte of a file that is over
  the limit, parses none of it, and sends no part of it. The server
  answers that the file is too large, as the page of the channel that
  asked states.
- **Not the frame.** The limit bounds the file. It does not bound the
  JSON object a server sends for the file, and the tag byte of a
  frame is not counted.

## The document

A server that reads the file sends exactly one JSON object of at
least three and at most seven members.

- **`name`.** A string: the frontmatter's `name`, the image's own
  name, as the image states it.
- **`schema`.** A JSON object: the frontmatter's `schema`, the JSON
  Schema of the `arguments` a container of the image accepts.
- **`body`.** A string: the body, verbatim.
- **`frontend`.** Present only with the value `true`, when the
  frontmatter's `frontend` is `true`. It states that the image's
  program serves a frontend, as the
  [frontend](/container-proxy-endpoints/frontend/) endpoint provides.
  Its absence states that the program serves none.
- **`icons`.** Present only with the frontmatter's object, when the
  frontmatter's `icons` has at least one member. It names the icons
  the image ships. Its absence states that the image ships none.
- **`chat`.** Present only with the frontmatter's object, when the
  frontmatter's `chat` is an object. It states how an agent's program
  chats. Its absence states that the program does not chat.
- **`structured_decisions`.** Present only with the frontmatter's
  object, when the frontmatter's `structured_decisions` is an object.
  It states how an agent's program makes structured decisions. Its
  absence states that the program makes no structured decision.
- **No other member.** The server reads no member further.

## Not a document

A file is not a document when it does not begin with a line that is
exactly `---`, when no later line is exactly `---`, when the
frontmatter is not a JSON object with the members stated above, when
`schema` is not an object, when a string of `icons` is not an icon
name, or when its bytes are not UTF-8. A file that is over the limit
of [The size](#the-size) is not read, and is neither a document nor
not a document: it is too large.
